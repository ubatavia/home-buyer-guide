# Calgary example: Glacier Ridge

A worked example of the workflow, built from **public** information gathered on 2026-10-19.

- One community: **Glacier Ridge** (northwest Calgary)
- Two builders: **Jayman BUILT** and **Cedarglen Homes**
- An **illustrative household**. The income, savings and contract rate in `scenario.md` are assumptions for the demo, not anyone's real finances.

Every figure carries a source and retrieval date. Where the evidence is thin the file says `null` or `unknown` and sets `data_confidence: low`. Prices are builder "starting from" figures taken from marketing pages and search snippets; no show-home visit or quote backs them, so they are not first-hand. Builder pages block automated reading, so confirm current prices on the builder sites before relying on anything here.
