# Floor plan comparison by size (Glacier Ridge)

Matching Jayman and Cedarglen plans of similar size. Data is in `floorplans.json`; every figure is a builder "starting from" price, not a quote. Retrieved 2026-10-19.

## The closest pair: Jayman Karma 24 vs Cedarglen Windsor

| | Jayman Karma 24 | Cedarglen Windsor |
|---|---|---|
| Size | 2,261 sq ft | 2,238 sq ft (1% smaller) |
| Bedrooms / baths | 3 / 2.5 | 3 / 2.5 |
| Garage | front attached, 2-car | front attached |
| Glacier Ridge starting price | $750,000s **pre-GST**, home and lot | $725,000 **incl. GST**, lot and home |
| Price incl. 5% GST | about $787,500 | $725,000 |
| $ per sq ft (incl. GST) | about $348 | about $324 |
| Features | oversized kitchen island, walk-through pantry or spice-kitchen option, main-floor bedroom option | open-to-above main living area, central upper bonus room, rear deck (from a Seton listing of the Windsor SSY 24) |

On these numbers the Windsor starts about **$62,500 (8%) lower** than the Karma once GST is counted the same way, for about the same floor area. On a 25-year, 10%-down, 4.0% scenario that is roughly **$305 a month** less (about $3,539 versus $3,844, before the association fee, tax and utilities).

**Why that is not a verdict:**
- Starting prices depend on lot and elevation, and the builders may define "starting" differently.
- Jayman prices are pre-GST. If you qualify for the First-Time Home Buyers' GST rebate (new homes up to $1M, rules to be verified, see `data/rules-ca-ab.json`), the GST gap may shrink or vanish, and the pre-GST comparison ($750,000 vs about $690,500) would then be the fairer one.
- Garage orientation of the Windsor comes from a Seton listing, not a Glacier Ridge page.
- The Windsor price was supplied from Cedarglen's page by the user. Cedarglen's site blocks automated reading, so it was not independently retrieved.

Jayman's Brooklyn 20 Glacier Ridge page, read directly, shows **the $520,000s, pre-GST**, so the earlier figure was wrong and has been replaced.
